# Клиентский юридический бриф

Автономная форма на русском языке для сбора сведений перед подготовкой претензии, иска или отзыва. Актуальная сокращённая версия: семь шагов, свободное описание проблемы вместо категории дела.

## Состав

- `index.html` — весь сайт: разметка, оформление и логика.
- `DEPLOY.md` — загрузка в GitHub и варианты размещения.
- `QUESTIONS.md` — содержание формы для редактирования и согласования.
- `.nojekyll` — отключение обработки Jekyll при размещении на GitHub Pages.
- `.gitignore` — исключения для локальных файлов и стандартных имён выгрузок.

Сборка, установка пакетов, база данных, сервер приложения, ключи API и переменные окружения не нужны. Сайт может размещаться по корневому адресу и в подпапке.

## Как работает

Клиент открывает страницу в браузере, проходит семь шагов, проверяет ответы и скачивает файл TXT. Дополнительно доступны JSON, черновик с последующим восстановлением, печать / PDF средствами браузера и отправка файла через системное меню, если оно поддерживается.

Документы передаются юристу отдельно. OCR в форму не встроен. Автоматической отправки ответов юристу нет.

## Данные

Код не отправляет ответы на сервер и не использует хранилище браузера. Ответы находятся в памяти открытой вкладки. При закрытии или обновлении страницы они пропадают, если не скачать результат или черновик.

Скачанные ответы и черновики содержат данные клиента. Их не следует загружать в Git. `.gitignore` исключает стандартные имена выгрузок; переименованные файлы требуют внимания при добавлении в репозиторий.

У хостинга могут быть собственные технические журналы посещений. Контроль доступа прежней площадки не переносится: доступность нового сайта определяется настройками нового хостинга.

## Быстрый старт

Распакуйте архив и откройте `index.html` на компьютере для просмотра. Для работы клиента с телефона разместите страницу и отправьте HTTPS-ссылку. Открытие локального HTML-файла на разных телефонах не гарантируется.

Инструкция по размещению — в [DEPLOY.md](DEPLOY.md).
